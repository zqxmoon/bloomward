# Bloomward

An original arena garden-defense game built for make.fun's "Make the best game"
bounty. You are the Warden of the last Bloomheart: pests swarm in waves to eat
the Bloom at the centre of the garden, and you hold them off with seed-bolts,
collect pollen, and choose one of three upgrades after every wave.

Play it by serving `game/` with any static file server and opening
`game/index.html` in a desktop browser — or run `node serve.ts` here and open
the address it prints.

Move with WASD or the arrow keys, aim with the mouse, hold the mouse button (or
Space) to fire. Enter starts, P pauses, M mutes, 1–3 pick an upgrade card.
