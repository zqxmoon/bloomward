Bloomward is an original arena garden-defense game in plain HTML/CSS/JS — no build, no network. You are the keeper of the last Bloomheart: pests stream in from all four edges in growing waves (crawlers, dart moths, sap spitters, brute beetles) while you move with WASD, aim with the mouse and fire seed shots. Clearing a wave offers a choice of 1 of 3 stackable upgrades (fire rate, damage, multishot, piercing, speed, health, bloom repair, magnet, thorns), kills build combo score, and golden pollen and hearts drop for recovery. Full loop: title screen with instructions and best score, HUD with wave/score/combo and dual health bars, pause, and a game-over screen with stats and restart. All sound is synthesized live with WebAudio.

## Run it

```sh
node --experimental-strip-types main.ts
```
